## 🧠 Overview

Kdenlive is a non-linear video editor designed for creating and editing video projects on Windows, Linux and macOS. It provides a multi-track timeline, video and audio effects, transitions, titles, subtitles, proxy editing and rendering tools. :contentReference[oaicite:0]{index=0}

The Windows version is available as both an installer and a standalone application. Current releases require 64-bit Windows 10 version 1809 or newer. :contentReference[oaicite:1]{index=1}

## 🚀 Key Features

| Feature | Description |
|---------|-------------|
| 🎬 Multitrack Editing | Work with multiple video and audio tracks on a flexible timeline |
| ✂️ Video Editing | Cut, trim, split, rearrange and combine clips |
| 🎨 Effects & Transitions | Apply video effects, audio effects and transitions |
| 📝 Subtitles | Create and manage subtitles directly within projects |
| 🎙️ Speech to Text | Supports speech recognition through integrated VOSK and Whisper options |
| 🎞️ Proxy Editing | Work with proxy media for smoother editing of demanding footage |
| 🎯 Keyframes | Animate supported effects using keyframe controls |
| 🔊 Audio Tools | Edit and mix audio alongside video content |
| 🖼️ Title Editor | Create text and title elements for videos |
| 📊 Video Scopes | Analyze video using available scopes and monitoring tools |
| 🖥️ Custom Workspace | Configure panels, toolbars, shortcuts and editing layouts |
| 📤 Rendering | Export completed projects using configurable render profiles |

## 💻 System Requirements

- **Operating System:** 64-bit Windows 10 version 1809 or newer
- **CPU:** Intel or AMD x86 processor
- **Memory:** 4 GB for SD, 8 GB for HD, 16 GB for 4K
- **GPU:** Compatible OpenGL 2.0 graphics hardware
- **Storage:** Additional space required for projects, source media and rendered files

For demanding 4K projects, Kdenlive recommends a more capable CPU and additional memory. Proxy editing, preview resolution and timeline preview rendering can help reduce playback load on lower-end systems. :contentReference[oaicite:2]{index=2}

## Additional Information for Windows Users

Kdenlive provides both an installable and standalone Windows version. The standalone edition does not require a traditional system installation and can be useful when working from a separate folder or external storage. :contentReference[oaicite:3]{index=3}

The editor includes a timeline-based workflow with configurable workspaces, effects, transitions, audio and video scopes, proxy workflows and rendering options. :contentReference[oaicite:4]{index=4}

Kdenlive also includes speech-to-text functionality using VOSK or Whisper. Whisper can use the CPU or, on supported systems, a CUDA-capable NVIDIA GPU for speech recognition. :contentReference[oaicite:5]{index=5}
